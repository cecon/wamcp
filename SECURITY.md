# Segurança

Não abra issues públicas com tokens, QR Codes, credenciais Baileys ou conversas. Use o recurso de reporte privado de vulnerabilidades do GitHub quando disponível.

Para revogar uma integração, abra Configurações → Conexões WhatsApp → conexão → Acesso MCP (ou ChatGPT) → revogar. Para desvincular WhatsApp, use a aba Conexão → Desconectar e sair. Essas operações são independentes: desvincular WhatsApp preserva o histórico local e os tokens de leitura.

Em caso de comprometimento do computador, revogue os aparelhos conectados pelo celular e substitua o token do túnel na Cloudflare. A desinstalação não deve ser considerada apagamento seguro dos dados no perfil do usuário.
