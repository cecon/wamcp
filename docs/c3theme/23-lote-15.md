# Lote 15 — Cabeçalho e lista de Conversas no C3Theme

> **Objetivo:** começar o maior bloco restante migrando a moldura da lista de conversas (cabeçalho, abas, vazio e carregar mais) e manter o MUI fora do chunk principal com a tela inteira em lazy. Resultado: **36/153 telas migradas (24%)**, 220 testes verdes em duas execuções.

---

## 1. O que mudou

| Peça                                                               | Migrado                                                                                                                | Continua no app                      |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| [ChatListHeader](../../src/agent/conversations/ChatListHeader.tsx) | título (`h1`), chip de status, “Ordenar conversas” e “Filtrar por status” em `IconButton` + `Menu` com `select` nativo | —                                    |
| [ChatList](../../src/agent/conversations/ChatList.tsx)             | moldura lateral, `Tabs`/`Tab` do MUI com contadores, estado vazio/erro e “Carregar mais”                               | `ConversationCard` e `BulkActionBar` |
| [Workspace](../../src/agent/Workspace.tsx)                         | `ConversationsScreen` virou `React.lazy` com `Suspense`                                                                | —                                    |

**Contratos preservados sem edição de teste:** `role="tab"` com nomes “Minhas”, “Todas” e “Não atribuídas + contador”; `role="tablist"`; `aria-label` “Ordenar conversas”/“Filtrar por status”; `combobox` **nativo** (o teste usa `selectOptions`); chip de status (“Abertas”/“Resolvidas”); vazio “Não há conversas ativas neste grupo.”; “Carregar mais”; heading do título.

## 2. Evidências (HEAD desta mudança)

| Verificação                          | Resultado                                                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `tsc` + ESLint + arquitetura + régua | verdes                                                                                                         |
| Suíte UI (2 execuções)               | **51 arquivos / 220 testes**, cobertura nos limiares                                                           |
| Testes de conversas                  | 9/9 (`conversations`, `new-chat`) + `shell` 6/6 — sem mudança de asserção                                      |
| Build                                | `ConversationsScreen` 73,6 kB (gzip 22,5) lazy; **`main` 603,2 kB (gzip 180,6)** — −77 kB ao sair do principal |
| Régua                                | **36 de 153 telas migradas (24%)**                                                                             |

## 3. Achado

**Migrar a lista puxaria o MUI para o `main`.** Como a tela de conversas é a inicial, a solução foi torná-la lazy: o bloco inteiro (lista + painel + thread + MUI) vive em um chunk de 73,6 kB, e o principal caiu para 603 kB. Nenhum teste precisou mudar (todos já esperavam com `findBy`).
