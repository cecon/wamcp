## 3. Achado

**Ao trocar `Button` do app pelo do MUI no mesmo arquivo, o `label=` antigo quebra o TypeScript** (o `SecretView` usava `<Button label="Concluir" />`). É a lista de checagem para os próximos arquivos grandes: procurar `label=`/`icon=` de `../ui/Button` antes de compilar.
