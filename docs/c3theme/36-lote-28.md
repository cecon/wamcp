# Lote 28 — Registro de auditoria no C3Theme

> **Objetivo:** iniciar as Configurações restantes migrando a página de auditoria para `SettingsC3` + `DataTable`, mantendo a paginação de servidor, os rótulos pt-BR e o alerta de erro. Resultado: **62 de 156 telas migradas (40%)**, 220 testes verdes em duas execuções.

---

## 1. O que mudou

| Peça                                                          | Migrado                                                                                                                                                                     | Continua no app                      |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| [AuditLogPage](../../src/agent/settings/AuditLogPage.tsx)     | `SettingsC3Page/Header` (“Registro de auditoria”), erro em `SettingsC3Error`, `DataTable` com Usuário/Ação/Tipo/ID/IP/Data e a paginação “Anterior/Página N/Próxima” em MUI | `http /audit_logs`, `formatDateTime` |
| [SettingsRouter](../../src/agent/settings/SettingsRouter.tsx) | `AuditLogPage` virou `lazy` no `LazyPage` (como as demais telas migradas)                                                                                                   | —                                    |

**Contratos preservados sem edição de teste:** heading “Registro de auditoria”; linhas com “Clonou”/“Automação”/“203.0.113.9”/data localizada; “Sistema” para autor nulo; “Redefiniu a verificação em duas etapas”; “Anterior” desabilitado na página 1; “Próxima” buscando `?page=2` e desabilitado na última; “Página 2”; `role="alert"` com “Apenas administradores”.

## 2. Evidências (HEAD desta mudança)

| Verificação                                       | Resultado                                                                                 |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `tsc` + ESLint + arquitetura + 300 linhas + régua | verdes                                                                                    |
| Suíte UI (2 execuções)                            | **51 arquivos / 220 testes**, cobertura nos limiares                                      |
| Testes afetados                                   | 10/10 (`security-admin`, `settings-parity`) sem mudança de asserção                       |
| Build                                             | `main` **421,9 kB (gzip 125,6)** — a auditoria entrou em chunk lazy pelo `SettingsRouter` |
| Régua                                             | **62 de 156 telas migradas (40%)**                                                        |

## 3. Achado

**Migrar a página não basta; o `SettingsRouter` precisa do `LazyPage`.** A primeira versão deixou o `AuditLogPage` importado estaticamente e o `main` subiu ~93 kB; ao movê-lo para `lazy` + `LazyPage`, o principal voltou para ~422 kB. Regra para os próximos lotes de Configurações: **toda página migrada entra no mapa `lazy` do router no mesmo commit**.
