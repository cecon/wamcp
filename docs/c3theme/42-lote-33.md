# Lote 33 — Chat do Agente de IA no `AssistantPanel` do C3Theme 0.3

> **Objetivo:** usar as melhorias que o time do C3Theme publicou no `@c3theme/chat` 0.3 (streaming, “Pensando…”, ferramentas,
> seletor de conversas e Parar) no chat do Agente de IA, **sem trocar a thread padrão** ainda: a frente nova fica atrás de
> `?c3assistant`. Resultado: **68 de 157 telas migradas (43%)**, worktree pnpm com **222 testes** verdes e a árvore antiga
> (pacote 0.1.0) seguindo verde com os testes novos pulados.

---

## 1. O que mudou

| Peça                                                              | O que faz                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AgentChatC3](../../src/agent/agentChat/AgentChatC3.tsx) **novo** | Adapta o estado atual do Agente de IA (mensagens, passos, sessões) para o contrato do `AssistantPanel`: mensagens C3, conversas a partir das sessões, `chat` com `generating` e envio; renderiza o painel com título do agente, estado vazio, seletor de sessões, dica do compositor e o aviso de sessão encerrada/limite de tokens |
| [AgentChatScreen](../../src/agent/agentChat/AgentChatScreen.tsx)  | Flag `?c3assistant` escolhe entre a thread antiga (padrão) e o painel C3; `sendText` envia pela API e injeta a mensagem na lista                                                                                                                                                                                                    |
| [C3Thread](../../src/agent/chat/C3Thread.tsx) (`?c3chat`)         | Passa `busy`/`onStop`/`hint` do `Composer` 0.3: botão vira **Parar** quando o transporte reporta geração e a dica “Enter envia · Shift+Enter” aparece                                                                                                                                                                               |

**Ponte para o pacote antigo:** o `AssistantPanel` é acessado dinamicamente (`* as chatUi`) e o componente mostra um aviso
(“rode `pnpm install`”) se o pacote instalado ainda for 0.1.0 — a árvore principal (npm, pacote velho) continua compilando e os
testes novos são `describe.skip` até a instalação.

## 2. Mapa de dados (nosso → C3)

- `ChatMessage` → `Message`: `role user` vira `direction: 'out'`/`format: 'plain'`; `agent` vira `in`/`markdown`; `error` vira
  `kind: 'system'`.
- Enquanto o backend pensa, entra uma mensagem **streaming** com `tools` (passos `tool` → `ToolCall`, último `running`) e
  `reasoning` (passos `note`) — é o que o painel mostra como “Pensando…”/ferramentas dentro da conversa.
- Sessões viram `Conversation[]` (“Conversa atual”/“Conversa N”, prévia e `updatedAt`), com `onSelectConversation`,
  `onNewConversation`; a exclusão de sessão não é oferecida (APIs atuais não têm).
